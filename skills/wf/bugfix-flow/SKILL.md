# Bug 修复流程

## 第一步：复现与理解

1. 确认错误信息的完整内容
2. 确认复现步骤
3. 确认预期行为 vs 实际行为

## 第二步：定位

1. 从错误信息中提取关键词
2. Grep 定位到出错代码
3. Read 出错代码上下文（至少前后 30 行）
4. 如有调用栈，沿调用链逐层定位

## 第三步：分析根因

1. 理解代码意图
2. 确认输入数据是否符合预期
3. 区分：逻辑错误 / 环境问题 / 数据问题 / 类型问题

## 第四步：修复

1. 针对根因修复（不要只修表面症状）
2. 保持最小改动
3. 考虑修复是否会影响其他代码

## 第五步：验证

1. 确认原 bug 已修复
2. 确认没有引入新问题
3. 运行 lint/test

## 调试方法论
- 复现 → 隔离 → 定位 → 修复 → 验证
- 先查日志/错误信息，再查代码
- 二分法缩小范围（注释掉一半代码看问题是否消失）
