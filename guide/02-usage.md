## 1. 日常使用

### 1.1 正常使用（AI 自动引导）

正常使用 AI 编程助手，全局基座（AGENTS.md）会引导 AI 按需加载经验：

```
用户发起任务
    ↓
AGENTS.md 触发经验加载协议
    ↓
AI 判断任务类型 → 加载对应经验
    ↓
执行任务（经验指导行动）
```

### 1.2 主动查询经验库

| 操作 | 命令 | 说明 |
|------|------|------|
| 浏览经验库索引 | `/exp` | 展示所有经验类别和条目 |
| 查询特定经验 | `/exp tp/search-first` | 直接加载指定经验 |

### 1.3 提取当前对话经验

| 操作 | 命令 | 说明 |
|------|------|------|
| 提取经验 | `/mine` | 从当前对话提取有价值经验 |

### 1.4 手动加载特定经验

在对话中输入：
```
加载 tp/search-first 经验
加载 wf/bugfix-flow 经验
```

## 2. 命令参考

### `/exp` — 浏览经验库索引

```
/exp
```

AI 会加载 `experience-index` 技能，展示当前可用的所有经验类别和条目，包括状态标注（✅核心/⚡待验证）。

### `/mine` — 提取经验

```
/mine
```

AI 会分析当前对话，提取其中有价值的经验（工具使用技巧、流程经验、案例教训、反模式），并将它们以独立 SKILL.md 文件的形式沉淀到经验库中。完成后自动更新 `experience-index`。

## 3. 加载策略

### 3.1 AI 自动加载策略

1. 先加载 `experience-index` 获取全景
2. 根据索引推荐，加载 1-2 条最相关的具体经验
3. 不要一次加载超过 3 条经验（节省上下文）

### 3.2 手动加载建议

| 任务类型 | 推荐加载 |
|---------|---------|
| 复杂任务开始前 | `experience-index` + 相关经验 |
| 遇到报错调试 | `cs/` 案例经验 |
| 不确定流程时 | `wf/` 流程经验 |
| 涉及工具选择 | `tp/` 工具优先级 |

---

## 4. 经验积累节奏

| 频率 | 操作 |
|------|------|
| 每次会话 | 全局基座自动引导按需加载 |
| 每次有价值任务后 | 半自动询问或手动 `/mine` |
| 每周 | `/exp` 浏览经验库，确认状态 |
| 每月 | 清理过时经验，合并相似经验 |

---

## 5. 经验状态说明

| 状态 | 标记 | 含义 |
|------|------|------|
| unverified | ⚡待验证 | 新提取，未经实践验证 |
| verified | ✅已验证(N) | 已被 N 次任务成功应用 |
| core | 🏆核心 | 多次验证的可靠经验 |

---

## 6. 半自动沉淀触发条件

### 6.1 AI 主动询问的时机

1. **任务完成时**：如果本次任务解决了非平凡问题，AI 会主动询问：
   > "本次任务包含有价值经验，是否需要 /mine 提取沉淀？"

2. **用户表达满意时**：如用户说"很好"、"解决了"等，AI 会询问是否提取。

### 6.2 不询问的情况

- 简单问答（无需提取）
- 经验索引中已有相同或高度相似的经验
- 用户明确表示不需要
