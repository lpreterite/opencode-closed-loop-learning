# OpenCode 闭环学习系统

> Closed-Loop Learning System for OpenCode

我把 OpenCode 当成学徒在带。

它干活的时候我就坐在旁边看着。做得好的地方，我不会多说——本来就应该这样做。做得不好的地方，我会纠正它。

每次纠正，它就记住一点。下次再遇到类似的活，干得就更顺一点。

---

## 概述

这个系统解决一个问题：**怎么把"带学徒"这件事固定下来，让 AI 真正学会**。

学徒刚来的时候，什么都不会。你让它找一个函数，它把整个项目读了一遍。你让它改个 bug，它改完不验证就跑。

后来它慢慢学会了——干活之前先搜索确认，代码改完跑一下测试，别一次改太多文件。

这些经验不是凭空来的。是我一次一次纠正出来的。

核心能力：

- **按需加载** — 学徒遇到问题时，加载对应的经验指导它
- **半自动沉淀** — 纠正完之后，说一声"/mine"，经验就存下来
- **失败驱动验证** — 学徒做对了不记录，做错了纠正才记录

---

## 原理

**失败才是数据。**

学徒做对了，我不知道是哪条经验在起作用。学徒做错了，我会纠正——这时候我才知道，这条经验有问题，或者根本就没这条经验。

所以验证靠的不是"计数"，而是**失败**。

流程是这样的：

```
学徒干活
     ↓ 做错了
你纠正它
     ↓
你说"可以 /mine 一下"
     ↓
它分析哪里出了问题
     ↓
这次纠正变成一条经验，存进知识库
     ↓
下次再遇到同样的情况，它就知道了
```

---

## 经验分类

六类知识模型：

| 类别 | 前缀 | 什么时候沉淀 |
|------|------|-------------|
| 方法论 | method/ | 我纠正了通用的做事步骤（含工具选择策略） |
| 领域工作流 | dw/ | 我纠正了本系统特有的操作流程 |
| 案例经验 | cs/ | 我告诉它这类问题应该怎么处理 |
| 偏好 | pf/ | 我表达了个人倾向 |
| 领域知识 | dk/ | 我指出了外部约束或事实 |
| 反模式 | ap/ | 我说"不要这样做" |

---

## 经验库

经验按六类组织，沉淀在 `~/.config/opencode/skills/` 下。每条经验以独立的 `SKILL.md` 文件存在，通过 `experience-index` 路由索引加载。

开箱时预置了基础经验模板，日常使用中通过 `/mine` 持续积累。

---

## 文件结构

```
setup.md         # ★ Agent 执行入口（按 ai-engineering 规范）
README.md        # 项目概述
skills/          # 经验库，沉淀在这里
│
├── experience-index/    # 经验路由索引（按需加载入口）
├── method/               # 方法论（通用可迁移，含工具选择策略）
├── dw/                   # 领域工作流（绑定特定系统）
├── cs/                   # 案例经验
├── pf/                   # 偏好（个人倾向）
├── dk/                   # 领域知识（稳定约束）
└── ap/                   # 反模式
│
docs/            # 文档根目录
├── STATUS.md            # 项目状态卡
├── README.md            # 文档索引
├── guide/               # 设计文档
│   ├── 01-architecture.md        # 系统架构
│   ├── 02-usage.md               # 日常使用指南
│   ├── 03-experience-management.md  # 经验管理
│   ├── 04-deployment.md          # 部署指南
│   └── 05-revamp.md              # 六类知识模型改版方案
├── agents/              # Agent 角色定义
│   └── experience-miner.md       # 经验矿工
├── setup/               # 工具安装指南
│   └── opencode.md               # OpenCode 部署
└── reference/           # 参考资料
    └── directory.md              # 目录结构规范
```

## 快捷命令

| 命令 | 用途 |
|------|------|
| `/exp` | 浏览经验库索引 |
| `/mine` | 从当前对话提取经验 |
